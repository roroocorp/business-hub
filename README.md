# Business Hub

Site statique de formations gratuites (français). Déployé depuis le dépôt `business-hub`.

Contenu initial : pages d'accueil, liste de formations (Bitcoin, Blockchain, Trading, Cybersécurité, Marketing), et pages de cours exemples.

Ce site est prévu sans section de contact ni formulaire d'inscription pour le moment — tout le contenu est accessible publiquement sans compte.

Activer GitHub Pages
1. Va dans Settings → Pages du dépôt `https://github.com/roroocorp/business-hub`.
2. Sous "Build and deployment", choisis la branche `main` et le dossier `/ (root)` puis clique sur Save.
3. L'URL publique sera `https://roroocorp.github.io/business-hub/` après quelques minutes.

Modifier le contenu
- Les pages des cours se trouvent dans `courses/`.
- Styles : `assets/css/styles.css`

Si tu veux plus tard ajouter un formulaire sécurisé ou un espace membre, je peux l'intégrer (Netlify/Supabase/Firebase). Pour l'instant le site est public et sans contact.
